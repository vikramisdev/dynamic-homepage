# 🎨 Doodle Search just like Google but more simple and lightweight

> A beautifully designed, Google-style search page built with HTML, CSS, and vanilla JavaScript.

[🌐 Live Demo](https://vikramisdev.github.io/doodle-search)

---

## ✨ About

**doodle-search** is a clean and interactive front-end search page inspired by Google's minimalism but with its own aesthetic flair. It’s fully responsive, made with just HTML, CSS, and JS—no frameworks, no libraries, just pure frontend craftsmanship.

## 🔍 Features

- 🎨 Animated and interactive UI
- 📱 Fully responsive layout (mobile-friendly)
- 🎯 Centered search bar with smooth hover/focus transitions
- 💡 Clean, modular code with reusable components
- ✨ Pure HTML, CSS, and JavaScript—no dependencies!

---

## 🧱 Tech Stack

| Technology  | Purpose            |
|-------------|---------------------|
| HTML5       | Structure            |
| CSS3        | Styling, transitions, layout |
| JavaScript  | Interaction (search input, events) |
